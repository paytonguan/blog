iOS 伪越狱玩法

发表于 2023-11-10 更新于 2026-08-08 分类于 iOS
本文字数： 27k 阅读时长 ≈ 25 分钟

不越狱也能实现类似越狱效果的工具与玩法，如 TrollStore、Filza、Apple Intelligence 等。

Filza 与 PlankFilza 修改

FilzaEscaped 修改 X 手势

  1. 打开 FilzaEscaped。
  2. 找到路径：/var/containers/Shared/SystemGroup/systemgroup.com.apple.mobilegestaltcache/Library/Caches/com.apple.MobileGestalt.plist
  3. 打开 com.apple.MobileGestalt.plist
  4. 选择 CacheExtra，再找 oPeik/9e8lQWMszEjbPzng。
  5. 点击 ArtworkDeviceSubType 右侧的（i）。
  6. 注意记下这个值，方便以后恢复。
  7. 将值修改为：2436
  8. 点击右上角存储，打开设置-显示与亮度-视图-改为放大，再改为标准，即可实现 X 手势。

PlankFilza 修改为 iPhone X 手势

  1. 打开 PlankFilza 工具。
  2. 找到路径：/var/containers/Shared/SystemGroup/systemgroup.com.apple.mobilegestaltcache/Library/Caches/com.apple.MobileGestalt.plist
  3. 找到 CacheExtra → oPeik/9e8IQWMszEjbPzng → ArtworkDeviceSubType
  4. 点击右边的符号，记下这个值（恢复时需要）。
  5. 把这个值改成：2436
  6. 点击”储存”，重启手机即可。

恢复方法：把 2436 改成原来的数值，点击右上角”储存”，重启手机即可恢复。

PlankFilza 修改运营商名称

  1. 打开 PlankFilza 工具。
  2. 找到路径：var/mobile/Libray/Carrier Bundles/Overlay
  3. 这里会显示所有运营商文件，打开设置-通用-关于本机查看运营商版本号，然后修改对应版本号的文件。移动：46000，联通：46001，电信：46007。
  4. 点击进去，往下拉找到”StatusBarlmages”文件，找到 ltem 0 和 ltem 1 或 ltem 2。
  5. 把中国移动/中国联通/中国电信修改为喜欢的名字。
  6. 右上角保存，返回 Overlay 点击右侧符号，把访问权限所有者隐藏改成 0555，右上角存储。
  7. 重启手机即可修改成功。

PlankFilza 修改关于本机信息

可修改关于本机的型号及版本号等。找到路径：/var/containers/Shared/SystemGroup/systemgroup.com.apple.mobilegestaltcache/Library/Caches/com.apple.MobileGestalt.plist，修改想改的内容，右上角保存，重启手机即可。

Apple Intelligence

国行开启 Apple Intelligence

用 misaka 工具（misaka26），需同时将 CH 改为 LL，并将型号改为 A2696。具体操作可参考以下视频和文章。

注意：如果重置了机子，修改会被改回去。

Apple Intelligence 启用条件

Apple Store ID、系统语言、系统地区、Siri 语言都需要在美国（iCloud 可以用国区）。挂墙到 GPT 出来登录成功即可，之后可以关墙。

如果将系统语言、系统地区、Siri 语言改为台湾，也可以用（Apple Store ID 仍可为美区），同理也可改到香港。

语言里可加简体中文作为备选，建议顺序：繁体中文-简体中文-English。

如果要用 GPT，必须长时间挂着墙。

MacDirtyCow

MacDirtyCow 利用 CVE-2022-46689 漏洞，支持 iOS 14.0-15.7.1，16.0-16.1.2，建议 15.0 及以上系统使用。

利用该漏洞，可通过交换同等大小文件的方式覆盖文件实现，从而实现一些特权操作。注意覆盖的文件不能大于原文件，覆盖后会一直存在并占用内存，重启后得到释放。当占用内存过大时，可能会导致手机变卡、小组件无法载入、第三方输入法无法使用、手机自动注销等。

FileSwitcherPro

和 Cowabunga 的自定义运行模式基本相同，下载链接如下。

打开后点击左上角设置，开启 Replace Plist Auto Padding 以在替换 plist 时自动调整大小。点击下面的+号，选择新建 Folder，完成后进入文件夹，点击+号选择 Bundle Item，可选择希望添加的项目，添加后开启，注销即可生效。

也可自行替换文件。创建 Original Item，ACTION 的 Type 选择 Replace File 即为替换文件。

更换App提示音

用Filza进入/var/containers/Bundle/Application/，然后找到需要替换修改提示音的App。以微信为例，为com.tencent.xin文件夹，进入后搜索in.caf，复制该文件路径。

打开 FileSwitcherPro，点击右侧+号，选择 Original Item 选项，在 TARGET 中填入上述路径。在 Type 中选择 Replace File，然后点击 File Select，选中要用于覆盖的音频文件。点击 Add，然后 Apply 和 Restart 即可。
